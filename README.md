# Retail Store Management System (SQL)

Welcome to the **Retail Store Management System**, a hands-on relational database project designed to mimic the backend operations of a local retail business. This project demonstrates core database administrator (DBA) skills, ranging from initial schema creation to advanced data analysis.

## Key Features & Capabilities
* **Database Schema Design:** Built structural tables for tracking `Products`, `Customers`, and `Orders` with proper data types and constraints.
* **Data Manipulation (CRUD):** Handled populating, updating, altering, and safely deleting records to maintain data integrity.
* **Business Insights & Aggregations:** Utilized SQL aggregation functions to analyze overall store performance, revenue, and top-selling products.
* **Trend Tracking:** Handled date-specific SQL functions to monitor sales patterns and customer purchase history over time.
* **Data Quality Control:** Implemented logic to handle `NULL` values and edge cases during query execution.

## Tech Stack
* **Language:** SQL
* **Concepts Covered:** DDL (Data Definition Language), DML (Data Manipulation Language), Joins, Aggregations, Date Functions.
